# Production Control Dashboard

A modern, responsive dashboard to monitor and manage factory production jobs, machine assignments, and delivery schedules.

## Features

- **Summary KPIs**: Quick overview of Total Jobs, Delayed Jobs, Due Today, and Completed Jobs.
- **Search & Filters**: Search jobs across ID, Product, Customer, Machine, and Status.
- **Sorting**: Sort jobs by Due Date or Quantity.
- **Interactive Details**: Click any job row to inspect detailed specifications and update its production status in real time.
- **Responsive Layout**: Designed for seamless use on both desktop and mobile screens.

## Getting Started

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```
